# RimTexture Inspector v1.1.0

## What's new

- Scan enabled mods from Steam Workshop and the local RimWorld `Mods` folder together.
- Add a direct RimSort rule-staging workflow for the selected preferred texture.
- Improve the interface with clearer source labels, aligned controls, and a direct RimSort rules-file picker.
- Ignore an exact mod combination to hide conflicts you have already handled.

## Requirements

- Windows x64
